# 🌐 Personal Portfolio Website

**Personal Portfolio** is a modern, responsive personal website designed to showcase my skills, professional experience, education, projects, and contact information. This website functions as an interactive online resume and portfolio to help potential employers, recruiters, and collaborators understand my background and capabilities as a **Flutter Mobile Application Developer** and **Full-Stack Engineer**.

## 📌 Project Overview

This portfolio website was created to present my mobile and web development skills and accomplishments in a clean, interactive, and modern format. It includes sections such as *About Me*, *Work Experience*, *Featured Projects*, *Skills*, and *Contact*.

---

## 🎯 Project Objectives

- ✅ Introduce myself and my background professionally  
- ✅ Highlight mobile engineering skills (Flutter & Dart) and backend systems (Laravel, PHP, MySQL)
- ✅ Showcase real production and portfolio projects with interactive screenshot sliders and live demo/repo links  
- ✅ Present my work experience, teaching background, and international achievements (YICMG 2026 Second Prize)
- ✅ Provide quick contact options (direct email copy, contact form, LinkedIn, Facebook)  
- ✅ Deliver responsive, accessible UI/UX with smooth micro-animations and dark/light mode  
- ✅ Host the site online using **GitHub Pages**
